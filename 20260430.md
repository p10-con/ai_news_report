# 2026-04-30 AI ニュース（木・ビジネス + デザイン）

## トピック 1 — Figma AI、生成 UI の最新アップデートで design-to-code 加速

https://www.figma.com/release-notes/

本日 4 月 29 日、Figma は Design・Draw・Buzz・Slides・FigJam の全プラットフォームにわたり AI 機能を拡張。Make Kits・Make Attachments により、既存コンポーネント・データ・デザインシステムを直接プロンプトに組み込み、アーキテクチャ図・ERD を FigJam から直接生成可能に。新 MCP ツール統合で Claude・Cursor・VS Code といった coding agent と Figma canvas が連携し、design file から secure API request で code 生成へ直結。brush・texture control の精度向上が design iteration cycle を短縮し、prototype から production への時間を劇的に削減。

## トピック 2 — Adobe CX Enterprise リリース、エージェント中心のクリエイティブワークフロー

https://news.adobe.com/news/2026/04/adobe-new-creative-agent

Adobe が Experience Cloud を置き換える AI-first プラットフォーム「CX Enterprise」を本年春リリース。AI コワーカー（persistent agent）が Photoshop・Premiere・Illustrator 間でタスク orchestrate し、マルチステップ workflow を自動化。agent-based architecture により、design→approval→deployment まで human intervention 最小化。Designer・Marketer・Developer の境界が消滅し、営業チーム・制作部門・engineering が同一 AI agent context で作業。Creative Cloud 全体の productivity が 3～5 倍向上見込み、enterprise marketing budget 配分の大幅見直し必須。

## トピック 3 — Adobe Firefly AI Assistant、会話型 UX で multi-app 生成ワークフロー

https://news.adobe.com/news/2026/04/adobe-new-creative-agent

Firefly AI Assistant が Creative Cloud 全体で自然言語 prompt から複数ステップの workflow を自動実行。「product launch video + social media assets + landing page」を single text prompt で一括生成、approval→revision cycle も agent が suggest。Lightroom での natural language search・film-inspired preset 自動生成が、photography workflow の高速化を実現。Agent が design decision を human preference から学習、iteration accuracy が飛躍的に向上。AI-human collaboration model が design tool の standard に昇華し、non-designer の content creator も professional-grade output が即座に生成可能に。
