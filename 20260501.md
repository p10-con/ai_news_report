# 2026-05-01 AI ニュース（金・技術 + 実装）

## DeepSeek V4：1.6 兆パラメータ、MIT ライセンスで全公開

https://www.bloomberg.com/news/articles/2026-04-24/deepseek-unveils-newest-flagship-a-year-after-ai-breakthrough

4月24日リリースの DeepSeek V4 は、1.6 兆パラメータ（有効4900億）、100万トークン context を備え、MIT ライセンスで完全オープンソース化。SWE-bench Verified で 80.6% を記録。フロントエンド開発者にとって、商用ライセンス制約なしに frontier-grade モデルを local deployment・fine-tuning できる機会。Hugging Face で weights 配布、LangChain・LiteLLM による unified API integration で、proprietary model との cost-benefit 判定が technical team で実施可能に。

## NVIDIA Nemotron 3：オープンモデルの効率化が 4 倍に加速

https://nvidianews.nvidia.com/news/nvidia-debuts-nemotron-3-family-of-open-models

Nemotron 3 family（Nano・Super・Ultra）は、Nemotron 2 比で 4 倍の throughput を実現。特に Nano は edge deployment・mobile agent 向けに最適化。agent-based application 構築時の model selection で、frontier model（高コスト）vs Nemotron 3（低レイテンシ・低コスト）の trade-off 判断が明確化。Next.js Edge Function・WebWorker での local inference 実装が現実的に。

## AI 推論最適化：inference workload が training を上回る、インフラ再編が加速

https://www.deloitte.com/us/en/insights/topics/technology-management/tech-trends/2026/ai-infrastructure-compute-strategy.html

2026年、生産環境での inference 需要が training を凌駕。inference-optimized chip 市場は年 50 billion 超へ成長。edge-distributed inference node（simpler tasks）と data center intensive node（complex model）の二層化が標準化。TensorMesh（LMCache）・RadixArk（SGLang routing）・Inferact（vLLM）など、multi-turn conversation・long-context model の serving infrastructure が急速に整備。frontend・backend team が共同で inference node 配置・routing strategy を決める必要が出現。
